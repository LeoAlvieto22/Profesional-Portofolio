# GitHub Pages Deployment — Updated Portfolio

This archive is prepared for your existing repository:

`https://github.com/LeoAlvieto22/Portofolio`

## Replace the website files

1. Download and extract `Leo_Alvieto_Andreardo_Portfolio_2026_Refresh.zip`.
2. Open the extracted folder.
3. Select all files inside it.
4. Upload them to the root of the `Portofolio` repository.
5. Choose to replace files with the same names.
6. Commit the changes to the same branch used by GitHub Pages.
7. Confirm Settings → Pages points to that branch and `/(root)`.
8. Wait for the GitHub Pages deployment to complete.

Do not upload the outer ZIP file itself. Do not upload the containing folder as an extra nested directory.

## Verify assets

After deployment, these paths should load:

- `/Portofolio/style.css`
- `/Portofolio/main.js`
- `/Portofolio/leo-profile.webp`
- `/Portofolio/CV_Leo_Alvieto_Andreardo_ATS.pdf`
- `/Portofolio/CV_Leo_Alvieto_Andreardo_Visual.pdf`

If a page looks cached, perform a hard refresh (`Ctrl + F5`) or open it in a private/incognito window.
