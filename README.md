## Run locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

No npm, build process, database, backend, or API key is required.

## Publish to the existing GitHub Pages repository

1. Extract the ZIP.
2. Open the extracted folder.
3. Upload **all files inside this folder** to the root of the existing `Portofolio` repository.
4. Replace files with the same names.
5. Commit changes to the branch currently used by GitHub Pages (usually `main`).
6. In Settings → Pages, ensure deployment uses the intended branch and `/ (root)` folder.
7. Wait for the deployment to finish, then hard-refresh the website.

Important: this package uses a flat root structure. `index.html`, `style.css`, `main.js`, `leo-profile.webp`, and the CV PDFs must be side by side in the repository root.
